03 Signal Types

타입 이름보다 어떤 블록에서 drive되는지가 더 중요합니다

wire

연결선에 가까운 net입니다. `assign` 출력이나 module 간 연결에서 자주 사용합니다.

reg

Verilog procedural block에서 값을 담는 변수입니다. 이름과 달리 항상 flip-flop은 아닙니다.

logic

SystemVerilog RTL의 기본 선택지입니다. 0, 1, X, Z를 표현할 수 있습니다.

X 전파 체험

입력 중 하나가 X이면 출력도 모호해질 수 있습니다. reset 누락이나 초기화 문제를 찾는 데 도움이 됩니다.

X AND 1 = X

04 always_comb / always_ff

조합논리와 순차논리를 다른 모양으로 작성합니다

d
mux en
DFF clk
q

조합논리

always_comb에서는 blocking assignment =를 사용하고, 모든 출력에 기본값을 줍니다.

순차논리

always_ff에서는 non-blocking assignment <=를 사용하고, register를 한 곳에서만 drive합니다.

06 Verification

좋은 testbench는 waveform 관찰을 pass/fail 판단으로 바꿉니다

Self-checking TB

stimulus, monitor, expected model, scoreboard, timeout을 갖추고 자동으로 실패를 보고합니다.

Assertion

FIFO overflow 금지, ready/valid 안정성, reset 후 초기값처럼 반드시 지킬 규칙을 코드로 적습니다.

Lint / CDC

width mismatch, latch 추론, multiple driver, CDC 구조 오류를 시뮬레이션 전후로 잡습니다.

짧은 확인

clock edge에서 register 값을 갱신할 때 일반적으로 사용하는 assignment는?

07 Circuit Lab

게이트를 직접 그리고 RTL 신호 전파를 확인합니다

부품

제어

출력 포트에서 입력 포트로 클릭해 연결합니다. 1 0 X

상태

MUX

조합논리

assign과 always_comb는 입력 변화가 곧 출력 변화로 이어지는 회로를 표현합니다.

X 전파

연결 누락, 초기화 누락, 루프 같은 문제는 시뮬레이션에서 X로 드러나는 경우가 많습니다.
