# 3. Longest Substring Without Repeating Characters

## 한 줄 개요 (직접 작성)

문자열에서 **중복 문자가 없는 가장 긴 연속 부분 문자열(substring)의 길이**를 구하는 문제.
(substring = 연속된 구간. 부분 수열 subsequence 과 다름)

## 입력 규모 메모 (복잡도 판단용)

문자열이 길어질 수 있어(수만 자) **O(n)** 슬라이딩 윈도우를 목표로 한다.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def lengthOfLongestSubstring(self, s: str) -> int` |
| C++ | `int lengthOfLongestSubstring(string s)` |
| C | `int lengthOfLongestSubstring(char* s)` |

## 힌트 (접근 방향, 직접 작성)

1. **슬라이딩 윈도우**: 두 포인터 `left`, `right` 로 구간 `[left, right]` 을 유지합니다.
2. `right` 를 한 칸씩 넓히면서, 새로 들어온 문자가 윈도우 안에 이미 있으면 `left` 를 그 문자 다음 위치로 당겨 중복을 없앱니다.
3. **해시맵/배열**에 "문자 → 마지막으로 본 인덱스" 를 저장하면 `left` 를 한 번에 점프시킬 수 있어 O(n) 입니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **슬라이딩 윈도우 + 마지막 위치 저장** | ⭐⭐⭐ | O(n) | O(k) | 중복이 생긴 지점까지 `left` 를 한 번에 이동할 수 있다. |
| 2 | 슬라이딩 윈도우 + set | ⭐⭐ | O(n) | O(k) | 이해하기 쉽지만 중복 제거를 위해 `left` 를 여러 번 움직일 수 있다. |
| 3 | 모든 부분 문자열 확인 | ⭐ | O(n³) 또는 O(n²) | O(k) | 직관적이지만 불필요한 재검사가 많다. |

> 이 문제에서는 **슬라이딩 윈도우 + 마지막 위치 저장**을 추천합니다.
> "현재 윈도우 안에 중복이 없어야 한다"는 조건을 포인터 두 개로 유지하기 좋습니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **마지막 위치 저장** | **O(n)** | **O(k)** | `right` 는 한 번씩 이동하고, `left` 는 뒤로 가지 않는다. |
| set 기반 윈도우 | O(n) | O(k) | 각 문자가 들어가고 나오는 횟수가 제한된다. |
| 브루트 포스 | O(n²) 이상 | O(k) | 많은 부분 문자열을 반복해서 검사한다. |

`k` 는 등장 가능한 문자 종류 수입니다.

## 슬라이딩 윈도우 시각 자료

```text
s = a b c a b c b b
    0 1 2 3 4 5 6 7

right=0: [a]       길이 1
right=1: [a b]     길이 2
right=2: [a b c]   길이 3
right=3: a가 중복

이전 a 위치 = 0
left를 1로 점프

현재 윈도우: [b c a]
             1 2 3
```

## 알고리즘 특징

- 윈도우 `[left, right]` 는 항상 중복 없는 상태를 유지합니다.
- 중복 문자를 만나면 `left = max(left, last_seen[문자] + 1)` 로 갱신합니다.
- `max` 를 쓰는 이유는 윈도우 밖에 있는 예전 중복 위치로 `left` 가 되돌아가는 것을 막기 위해서입니다.
