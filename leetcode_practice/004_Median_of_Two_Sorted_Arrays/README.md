# 4. Median of Two Sorted Arrays

## 한 줄 개요 (직접 작성)

**정렬된 두 배열**을 합쳤다고 했을 때 전체의 **중앙값(median)** 을 구하는 문제.
(중앙값: 정렬된 전체에서 가운데 값. 개수가 짝수면 가운데 두 값의 평균)

## 핵심 제약 메모 (직접 작성)

전체 실행 시간 복잡도가 **`O(log(m+n))`** 으로 요구되는 게 이 문제의 난이도 포인트.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float` |
| C++ | `double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2)` |
| C | `double findMedianSortedArrays(int* nums1, int nums1Size, int* nums2, int nums2Size)` |

## 힌트 (접근 방향, 직접 작성)

1. **쉬운 방법 (O(m+n))**: 두 배열을 병합 정렬하듯 합친 뒤 가운데 값을 고릅니다. 정답이긴 하나 요구 복잡도는 아닙니다.
2. **요구 복잡도 O(log(m+n))**: 더 짧은 배열에서 **분할 지점(partition)** 을 이분 탐색합니다.
   - 두 배열을 각각 왼쪽/오른쪽으로 나눠, 왼쪽 묶음의 모든 원소 ≤ 오른쪽 묶음의 모든 원소가 되도록 경계를 맞춥니다.
   - 경계 조건: `maxLeft1 <= minRight2` 그리고 `maxLeft2 <= minRight1`.
3. 먼저 1번(쉬운 방법)으로 정확성부터 확보한 뒤, 2번에 도전해도 좋습니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **짧은 배열 기준 이분 탐색 partition** | ⭐⭐⭐ | O(log min(m, n)) | O(1) | 문제의 요구 복잡도를 만족하고 병합 없이 중앙값을 바로 찾는다. |
| 2 | 병합하며 중앙까지만 진행 | ⭐⭐ | O(m+n) | O(1) | 구현이 쉽고 실수하기 적지만 요구 복잡도는 만족하지 않는다. |
| 3 | 전체 병합 후 중앙값 | ⭐ | O(m+n) | O(m+n) | 가장 쉽지만 추가 배열을 만든다. |

> 이 문제에서는 **partition 이분 탐색**을 추천합니다.
> 두 배열이 이미 정렬되어 있으므로, 전체를 합치지 않고도 왼쪽 절반과 오른쪽 절반의 경계만 맞추면 됩니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **partition 이분 탐색** | **O(log min(m, n))** | **O(1)** | 더 짧은 배열의 분할 위치만 이분 탐색한다. |
| 중앙까지만 병합 | O(m+n) | O(1) | 중앙 위치까지 포인터를 전진시킨다. |
| 전체 병합 | O(m+n) | O(m+n) | 모든 원소를 새 배열에 담는다. |

## Partition 시각 자료

```text
A = [1, 3, 8]
B = [2, 7, 10, 11]

전체 왼쪽 절반 크기를 맞추도록 나누기

A: [1, 3] | [8]
B: [2, 7] | [10, 11]

왼쪽 최댓값: max(3, 7) = 7
오른쪽 최솟값: min(8, 10) = 8

왼쪽의 모든 값 <= 오른쪽의 모든 값이면 partition 성공
왼쪽 절반 크기를 (전체 길이 + 1) / 2 로 잡으면
전체 개수가 홀수일 때 중앙값 = 왼쪽 최댓값
```

## 알고리즘 특징

- 항상 **더 짧은 배열**에서 이분 탐색해야 구현이 안정적입니다.
- 경계 밖 값은 `-∞`, `+∞` 로 취급하면 빈쪽 처리가 쉬워집니다.
- 핵심 조건은 `maxLeftA <= minRightB` 그리고 `maxLeftB <= minRightA` 입니다.
