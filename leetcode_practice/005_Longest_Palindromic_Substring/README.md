## 한 줄 개요 (직접 작성)

문자열에서 **가장 긴 팰린드롬(palindrome) 연속 부분 문자열**을 찾아 반환하는 문제.
(팰린드롬 = 앞에서 읽으나 뒤에서 읽으나 같은 문자열, 예: aba, abba)

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def longestPalindrome(self, s: str) -> str` |
| C++ | `string longestPalindrome(string s)` |
| C | `char* longestPalindrome(char* s)` |

## 힌트 (접근 방향, 직접 작성)

1. **중심 확장(Expand Around Center)**: 각 위치를 팰린드롬의 중심으로 보고 양옆으로 확장합니다.
   - 중심은 두 종류: 글자 1개(홀수 길이 "aba")와 글자 사이(짝수 길이 "abba").
   - 총 `2n-1` 개의 중심에서 확장 → O(n²) 시간, O(1) 공간.
2. **DP**: `dp[i][j]` = "s[i..j] 가 팰린드롬인가" 를 채워나가는 방법도 있습니다. O(n²) 시간/공간.
3. C 에서는 반환 문자열을 `malloc` 으로 할당하고 끝에 `'\0'` 을 넣어야 합니다.

|----------|----------|--------|------|------|---------------------|
| 1 | **중심 확장** | ⭐⭐⭐ | O(n²) | O(1) | 구현이 짧고, 팰린드롬의 정의를 그대로 이용하며, 추가 배열 없이 통과하기 좋다. |
| 2 | DP | ⭐⭐ | O(n²) | O(n²) | 부분 문자열의 팰린드롬 여부를 표로 정리해 이해하기 좋지만 메모리를 더 쓴다. |

> 이 문제에서는 **중심 확장**을 기본 풀이로 추천합니다.
> 팰린드롬은 가운데에서 양쪽 문자가 같은지 확인하면 자연스럽게 판별되기 때문입니다.

## 중심 확장 시각 자료

예시 문자열을 `babad` 라고 생각해 봅시다.
각 위치를 중심으로 잡고 왼쪽/오른쪽을 동시에 비교합니다.

```text
s = b a b a d
    0 1 2 3 4

홀수 길이 중심: index 1의 'a'

      L C R
      ↓ ↓ ↓
      b a b a d
      0 1 2 3 4

1단계: s[1] == s[1]  → "a"
2단계: s[0] == s[2]  → "bab"
3단계: 왼쪽 범위 밖     → 확장 종료

현재 후보: "bab"
```

짝수 길이 팰린드롬도 놓치지 않으려면 **문자 사이**를 중심으로 봐야 합니다.

```text
s = c b b d
    0 1 2 3

짝수 길이 중심: index 1과 2 사이

      L R
      ↓ ↓
      c b b d
      0 1 2 3

1단계: s[1] == s[2]  → "bb"
2단계: s[0] != s[3]  → 확장 종료

현재 후보: "bb"
```

## 중심 확장의 핵심 특징

- **중심은 총 `2n - 1`개**입니다.
  - 홀수 중심: 문자 하나를 중심으로 확장합니다. 예: `"aba"`
  - 짝수 중심: 문자와 문자 사이를 중심으로 확장합니다. 예: `"abba"`
- 각 중심에서 최악의 경우 문자열 양끝까지 확장할 수 있으므로 **시간 복잡도는 O(n²)** 입니다.
- 별도의 DP 테이블이 필요 없으므로 **공간 복잡도는 O(1)** 입니다.
- 구현에서는 확장이 끝난 뒤의 `left`, `right` 가 한 칸씩 벗어나 있으므로 실제 팰린드롬 구간은 보통 `left + 1` 부터 `right - 1` 입니다.

## 풀이 뼈대

```text
best_start = 0
best_len = 1

for center in 0..n-1:
    홀수 팰린드롬 확장: expand(center, center)
    짝수 팰린드롬 확장: expand(center, center + 1)
    더 긴 결과가 나오면 best_start, best_len 갱신

return s[best_start : best_start + best_len]
```

## DP 접근은 언제 좋은가?

DP는 `s[i..j]` 가 팰린드롬인지 여부를 표로 저장합니다.

```text
dp[i][j] = true 조건

1. s[i] == s[j]
2. j - i <= 2 이거나 dp[i + 1][j - 1] == true
```

```text
문자열: a b b a

      j→ 0  1  2  3
i↓       a  b  b  a
0 a      T  F  F  T   ← "abba"
1 b         T  T  F   ← "bb"
2 b            T  F
3 a               T
```

DP는 표가 눈에 보여 원리를 이해하기 좋지만, 길이가 커질수록 `n x n` 공간을 사용합니다. 그래서 이 문제의 실전 기본 풀이는 보통 **중심 확장**이 더 간결합니다.
