## 한 줄 개요 (직접 작성)

문자열을 지정된 행 수의 지그재그 형태로 배치한 뒤, 행별로 이어 붙인 결과를 구하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def convert(self, s: str, numRows: int) -> str` |
| C++ | `string convert(string s, int numRows)` |
| C | `char* convert(char* s, int numRows)` |

## 힌트 (접근 방향, 직접 작성)

1. `numRows == 1` 이거나 문자열 길이가 행 수보다 작으면 원래 문자열이 그대로 답입니다.
2. 각 행을 담을 버퍼를 만들고, 현재 행과 이동 방향을 갱신하며 문자를 하나씩 넣으면 됩니다.
3. 한 사이클 길이는 `2 * numRows - 2` 입니다. 이 규칙으로 행별 인덱스를 직접 계산하는 방법도 있습니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **행별 버퍼 시뮬레이션** | ⭐⭐⭐ | O(n) | O(n) | 지그재그로 내려갔다 올라가는 움직임을 그대로 구현해 이해하기 쉽다. |
| 2 | 사이클 인덱스 계산 | ⭐⭐ | O(n) | O(n) | 추가 행 배열 없이 규칙적으로 읽을 수 있지만 인덱스 계산이 까다롭다. |
| 3 | 2차원 배열 구성 | ⭐ | O(n) | O(n·rows) | 그림과 비슷하지만 빈 칸이 많아 비효율적이다. |

> 이 문제에서는 **행별 버퍼 시뮬레이션**을 추천합니다.
> 현재 행과 방향만 관리하면 모든 문자를 한 번씩 배치할 수 있습니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **행별 버퍼 시뮬레이션** | **O(n)** | **O(n)** | 각 문자를 정확히 한 번 행 버퍼에 넣고 마지막에 합친다. |
| 사이클 인덱스 계산 | O(n) | O(n) | 결과 문자열을 만들기 위해 모든 문자를 한 번씩 읽는다. |
| 2차원 배열 구성 | O(n) | O(n·rows) | 빈 칸까지 저장할 수 있다. |

## 지그재그 이동 시각 자료

```text
numRows = 3

행 0: P   A   H
행 1: A P L S I
행 2: Y   I   R

이동 방향:

0행 → 아래로
1행 → 아래로
2행 → 위로
1행 → 위로
0행 → 아래로 반복
```

## 알고리즘 특징

- `current_row` 가 0 또는 `numRows - 1` 에 도착하면 방향을 바꿉니다.
- `numRows == 1` 은 방향 전환이 불가능한 특수 케이스라 먼저 반환하는 것이 안전합니다.
- 행별 문자열을 마지막에 순서대로 이어 붙이면 정답이 됩니다.
