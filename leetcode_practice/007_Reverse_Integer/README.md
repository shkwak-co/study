## 한 줄 개요 (직접 작성)

부호 있는 정수의 자릿수를 뒤집고, 32비트 정수 범위를 벗어나면 0을 반환하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def reverse(self, x: int) -> int` |
| C++ | `int reverse(int x)` |
| C | `int reverse(int x)` |

## 힌트 (접근 방향, 직접 작성)

1. `x % 10` 으로 마지막 자릿수를 꺼내고 `x / 10` 으로 줄여가며 결과를 만듭니다.
2. 결과에 새 자릿수를 붙이기 전에 32비트 정수 범위를 넘는지 검사해야 합니다.
3. Python은 정수 오버플로가 없으므로 최종 결과나 중간 결과를 직접 범위 검사해야 합니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **자릿수 추출 + 오버플로 사전 검사** | ⭐⭐⭐ | O(d) | O(1) | 숫자 연산만 사용하고 32비트 범위 초과를 안전하게 막을 수 있다. |
| 2 | 문자열 변환 | ⭐⭐ | O(d) | O(d) | 구현은 쉽지만 문제 의도인 오버플로 처리를 덜 연습하게 된다. |

> 이 문제에서는 **자릿수 추출 방식**을 추천합니다.
> `pop = x % 10`, `result = result * 10 + pop` 흐름으로 뒤집는 과정을 직접 제어할 수 있습니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **자릿수 추출** | **O(d)** | **O(1)** | 자릿수 개수 `d` 만큼 반복하고 변수 몇 개만 사용한다. |
| 문자열 변환 | O(d) | O(d) | 숫자를 문자열로 바꾸고 뒤집은 문자열을 저장한다. |

`d` 는 숫자의 자릿수입니다. 32비트 정수에서는 최대 10자리 정도입니다.

## 자릿수 뒤집기 시각 자료

```text
x = 123
result = 0

pop = 3, x = 12
result = 0 * 10 + 3 = 3

pop = 2, x = 1
result = 3 * 10 + 2 = 32

pop = 1, x = 0
result = 32 * 10 + 1 = 321
```

## 알고리즘 특징

- 새 자릿수를 붙이기 전 `result * 10 + pop` 이 32비트 범위를 넘는지 확인합니다.
- C/C++에서는 실제 오버플로가 발생하기 전에 검사해야 합니다.
- 음수는 부호를 따로 처리하거나, 언어의 나머지 연산 규칙을 조심해서 다뤄야 합니다.
