## 한 줄 개요 (직접 작성)

문자열 앞부분을 규칙에 맞게 읽어 부호 있는 32비트 정수로 변환하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def myAtoi(self, s: str) -> int` |
| C++ | `int myAtoi(string s)` |
| C | `int myAtoi(char* s)` |

## 힌트 (접근 방향, 직접 작성)

1. 앞쪽 공백을 건너뛰고, 선택적인 부호를 읽은 뒤, 숫자가 이어지는 동안만 처리합니다.
2. 숫자가 아닌 문자를 만나면 거기서 변환을 멈춥니다.
3. 결과가 32비트 정수 범위를 넘으면 최솟값 또는 최댓값으로 고정합니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **단계별 파싱 + 범위 clamp** | ⭐⭐⭐ | O(n) | O(1) | 문제의 규칙을 순서대로 처리하고 오버플로를 즉시 제어할 수 있다. |
| 2 | 정규식/라이브러리 파싱 | ⭐ | O(n) | O(n) | 간단해 보이지만 LeetCode 의도와 언어별 세부 규칙을 놓치기 쉽다. |

> 이 문제에서는 **직접 파싱**을 추천합니다.
> 공백, 부호, 숫자, 종료 조건, 범위 제한을 명확한 단계로 나누면 실수가 줄어듭니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **단계별 파싱** | **O(n)** | **O(1)** | 문자열을 앞에서부터 최대 한 번만 읽는다. |
| 정규식/라이브러리 | O(n) | O(n) | 매칭 결과 문자열이나 중간 객체가 생길 수 있다. |

## 파싱 흐름 시각 자료

```text
s = "   -42 with words"

1. 공백 건너뛰기
      ↓
   -42 with words

2. 부호 읽기: '-'

3. 숫자 읽기
   4 → result = 4
   2 → result = 42

4. 공백/문자 ' ' 를 만나면 종료

최종값 = -42
```

## 알고리즘 특징

- 처리 순서는 **공백 → 부호 → 숫자 → 종료** 입니다.
- 숫자를 붙일 때마다 `result = result * 10 + digit` 형태로 갱신합니다.
- 범위를 넘으면 즉시 `INT_MIN` 또는 `INT_MAX` 로 고정해 반환하면 됩니다.
