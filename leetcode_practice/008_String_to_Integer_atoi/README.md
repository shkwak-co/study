## 한 줄 개요 (직접 작성)

문자열 앞부분을 규칙에 맞게 읽어 부호 있는 32비트 정수로 변환하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def myAtoi(self, s: str) -> int` |
| C++ | `int myAtoi(string s)` |
| C | `int myAtoi(char* s)` |

## 힌트 (접근 방향, 직접 작성)

1. 앞쪽 공백을 건너뛰고, 선택적인 부호를 읽은 뒤, 숫자가 이어지는 동안만 처리합니다.
2. 숫자가 아닌 문자를 만나면 거기서 변환을 멈춥니다.
3. 결과가 32비트 정수 범위를 넘으면 최솟값 또는 최댓값으로 고정합니다.
