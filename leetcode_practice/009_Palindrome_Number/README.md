## 한 줄 개요 (직접 작성)

정수를 앞에서 읽은 값과 뒤에서 읽은 값이 같은 팰린드롬 숫자인지 판별하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def isPalindrome(self, x: int) -> bool` |
| C++ | `bool isPalindrome(int x)` |
| C | `bool isPalindrome(int x)` |

## 힌트 (접근 방향, 직접 작성)

1. 음수는 부호 때문에 팰린드롬이 될 수 없습니다.
2. 문자열로 바꾸어 양쪽 끝을 비교하면 구현이 쉽습니다.
3. 수학적으로 풀려면 숫자의 뒤 절반만 뒤집어 앞 절반과 비교할 수 있습니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **뒤 절반만 뒤집기** | ⭐⭐⭐ | O(d) | O(1) | 전체 숫자를 뒤집지 않아 오버플로 위험이 작고 공간도 적게 쓴다. |
| 2 | 문자열 양끝 비교 | ⭐⭐ | O(d) | O(d) | 가장 쉽고 직관적이지만 문자열 저장 공간이 필요하다. |
| 3 | 전체 숫자 뒤집기 | ⭐ | O(d) | O(1) | 단순하지만 큰 수에서는 오버플로를 조심해야 한다. |

> 이 문제에서는 **뒤 절반만 뒤집기**를 추천합니다.
> 팰린드롬 여부는 앞 절반과 뒤집은 뒤 절반만 비교해도 충분합니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **뒤 절반만 뒤집기** | **O(d)** | **O(1)** | 자릿수의 절반 정도만 추출하고 변수만 사용한다. |
| 문자열 양끝 비교 | O(d) | O(d) | 문자열 변환 후 양쪽 포인터로 비교한다. |
| 전체 숫자 뒤집기 | O(d) | O(1) | 모든 자릿수를 뒤집어 원본과 비교한다. |

## 뒤 절반 뒤집기 시각 자료

```text
x = 1221

앞쪽 남은 수 x     뒤집은 뒤쪽 reversed
1221              0
122               1
12                12

x == reversed 이므로 팰린드롬
```

홀수 자리 숫자는 가운데 숫자를 제거하고 비교합니다.

```text
x = 12321

진행 후:
x = 12
reversed = 123

가운데 숫자 3 제거:
reversed / 10 = 12

x == reversed / 10 이므로 팰린드롬
```

## 알고리즘 특징

- 음수는 바로 `false` 입니다.
- 0이 아닌데 마지막 자리가 0인 수는 팰린드롬이 될 수 없습니다. 예: `10`
- 반복 조건은 보통 `x > reversed` 로 두어 뒤 절반만 뒤집습니다.
