## 한 줄 개요 (직접 작성)

문자열 전체가 `.` 과 `*` 를 포함한 패턴과 완전히 일치하는지 판단하는 문제.

## 함수 시그니처 (풀 형태)

| 언어 | 시그니처 |
|------|----------|
| Python | `def isMatch(self, s: str, p: str) -> bool` |
| C++ | `bool isMatch(string s, string p)` |
| C | `bool isMatch(char* s, char* p)` |

## 힌트 (접근 방향, 직접 작성)

1. 부분 일치가 아니라 문자열 전체가 패턴 전체와 맞아야 합니다.
2. `.` 은 임의의 문자 하나, `*` 는 바로 앞 요소의 0회 이상 반복으로 생각합니다.
3. `dp[i][j]` 를 `s` 의 앞 `i`글자와 `p` 의 앞 `j`글자가 일치하는지로 두면 체계적으로 풀 수 있습니다.

## 추천 알고리즘 한눈에 보기

| 우선순위 | 알고리즘 | 추천도 | 시간 | 공간 | 왜 추천하는가 |
|----------|----------|--------|------|------|---------------|
| 1 | **DP 테이블** | ⭐⭐⭐ | O(mn) | O(mn) | `.` 과 `*` 의 경우를 표로 분리해 전체 일치 여부를 안정적으로 계산한다. |
| 2 | 재귀 + 메모이제이션 | ⭐⭐ | O(mn) | O(mn) | 점화식이 직관적이지만 재귀 깊이와 인덱스 처리를 조심해야 한다. |
| 3 | 순수 백트래킹 | ⭐ | 지수 시간 | O(m+n) | `*` 때문에 같은 상태를 반복 방문해 매우 느려질 수 있다. |

> 이 문제에서는 **DP 테이블**을 추천합니다.
> 패턴의 `*` 가 "0번 사용"과 "1번 이상 사용" 두 갈래를 만들기 때문에, 이미 계산한 상태를 저장하는 방식이 중요합니다.

## 복잡도 요약

| 풀이 | 시간 복잡도 | 공간 복잡도 | 핵심 이유 |
|------|-------------|-------------|-----------|
| **DP 테이블** | **O(mn)** | **O(mn)** | 문자열 길이 `m`, 패턴 길이 `n` 의 모든 상태를 한 번씩 계산한다. |
| 재귀 + 메모이제이션 | O(mn) | O(mn) | 가능한 `(i, j)` 상태를 캐시에 저장한다. |
| 순수 백트래킹 | 지수 시간 | O(m+n) | `*` 선택지가 중복 상태를 계속 만든다. |

## DP 상태 시각 자료

```text
dp[i][j] = s의 앞 i글자와 p의 앞 j글자가 완전히 일치하는가?

        p 앞부분
        ""   a   *
s ""    T    F   T
  a     F    T   T
  aa    F    F   T

패턴 "a*" 는
- a를 0번 쓰면 빈 문자열과 일치
- a를 여러 번 쓰면 "a", "aa" 와도 일치
```

## 핵심 점화식

```text
현재 패턴 문자가 일반 문자 또는 '.' 인 경우:
dp[i][j] = dp[i-1][j-1] && char_match(s[i-1], p[j-1])

현재 패턴 문자가 '*' 인 경우:
1. 앞 요소를 0번 사용:
   dp[i][j] = dp[i][j-2]

2. 앞 요소를 1번 이상 사용:
   dp[i][j] = char_match(s[i-1], p[j-2]) && dp[i-1][j]
```

## 알고리즘 특징

- `*` 는 단독 문자가 아니라 **바로 앞 요소를 반복시키는 연산자**입니다.
- `dp[0][j]` 초기화가 중요합니다. 예를 들어 `a*`, `a*b*` 는 빈 문자열과 일치할 수 있습니다.
- 전체 일치 문제이므로 최종 답은 `dp[m][n]` 입니다.
